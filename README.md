# Rocky Codex Pet

A custom Codex v2 pet inspired by Rocky: a faceless triangular-bodied Eridian with grounded jointed stone limbs, turquoise mineral patches, blunt tapered contacts, and musical-tone speech via digital converter.

## Install

After this repository is pushed to GitHub, install Rocky with this Codex pet link:

```text
codex://pets/install?name=Rocky&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2FChrisLounsbury%2FRocky%2Fmain%2Fspritesheet.webp&description=A%20faceless%20triangular-bodied%20Eridian%20pet%20with%20grounded%20stone%20limbs%2C%20turquoise%20mineral%20patches%2C%20and%20musical-tone%20speech%20via%20digital%20converter.&spriteVersionNumber=2
```

If your browser does not open `codex://` links automatically, copy the link and open it from a browser address bar, or on macOS run:

```bash
open 'codex://pets/install?name=Rocky&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2FChrisLounsbury%2FRocky%2Fmain%2Fspritesheet.webp&description=A%20faceless%20triangular-bodied%20Eridian%20pet%20with%20grounded%20stone%20limbs%2C%20turquoise%20mineral%20patches%2C%20and%20musical-tone%20speech%20via%20digital%20converter.&spriteVersionNumber=2'
```

## Manual install

Copy these files into:

```text
~/.codex/pets/rocky/
```

Required files:

- `pet.json`
- `spritesheet.webp`

Then open Codex Settings > Pets and refresh/select custom pets if needed.

## Format

- Codex pet sprite version: `2`
- Atlas size: `1536x2288`
- Layout: `8 columns x 11 rows`
- Cell size: `192x208`
